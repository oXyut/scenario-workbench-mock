# シナリオ制作ワークベンチ — デザインモック

[モックを開く](https://oxyut.github.io/scenario-workbench-mock/)

新クトゥルフ神話TRPGのシナリオ制作を想定した、PC向けの操作できる画面案です。サンプル「灯台の消えた夜」はモック用の創作です。公式本文・ルールの転載はありません。

シーンの流れを図で見ながら、選択した場面の本文・情報・アイテム・判定・ギミックを確認します。最終組版は別工程の画面案です。

## 試すこと

1. 図でシーンを選び、右の本文と関係を確認する。
2. 「編集」から自由記述・構造化を切り替えて保存する。
3. 「戻す」「やり直す」を使い、再編集する。
4. 下の相談欄で音声デモとチャットデモを試す。
5. 「入手場所の変更案」で影響を見て、候補の採用と代替情報源の保持を試す。
6. 「点検」で整合性と推奨技能の根拠を見る。
7. 「履歴」で版を復元する。
8. 「組版へ」で別工程の受渡し案を見る。

## モックの範囲

- 画面幅1280px以上のPCブラウザを推奨します。
- 音声・AI応答は固定デモです。録音・外部AI接続・課金はありません。
- 保存・履歴はブラウザ内の一時データです。再読み込みすると初期状態に戻ります。
- 整合性と技能の根拠はサンプルに設定した関係から表示します。汎用的な意味解析は未実装です。
- 自由記述を自動で構造化する機能、永続化、最終組版は未実装です。
- スキーマ、大変更の基準、保存方式、組版形式、技術選定は未決です。
- モック公開はレビューのためのもので、本実装の承認を意味しません。

## 公開方法

GitHub Actionsで `site/` だけを静的ファイルとしてGitHub Pagesへデプロイします。カスタムドメインや外部サービスは使用しません。
